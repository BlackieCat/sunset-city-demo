# Sunset City

A small, playable GTA-inspired top-down city demo built with HTML Canvas and vanilla JavaScript. 非官方粉丝概念 Demo。

## 开始游戏

下载并用现代浏览器打开 `index.html`，点击“进入日落之城”。不需要安装依赖或联网。

也可以启动本地服务：

```sh
python -m http.server 8080
```

然后在浏览器打开 localhost:8080。

## 玩法

- 城市自由探索、步行和上下车
- 车辆加速、倒车、手刹漂移和碰撞
- 警车追捕、通缉等级、射击和脱离追捕
- 取货、送货、逃脱任务以及现金奖励
- 小地图、目标方向、生命值和车辆耐久
- 暂停、重新开始、可选合成音效和触屏按钮
- 最高任务收入保存在当前浏览器本地

| 操作 | 按键 |
| --- | --- |
| 移动 / 驾驶 | WASD / 方向键 |
| 上下车 | E |
| 奔跑 / 漂移 | Shift |
| 沿面向方向射击 | Space |
| 暂停 / 帮助 | P / Esc |

首个任务：按 E 进入旁边的粉色跑车，按 W 前往黄色取货点。减速进入光圈自动取货，再送往绿色交货点，最后甩掉追捕。

## 技术与验证

单个 HTML 文件，内含 CSS 和 JavaScript，无第三方资源和后端服务。浏览器实测进入游戏、上车和画面；模拟逻辑测试覆盖加速、取货、交货、逃脱、奖励、射击、暂停、重开及绘制调用。完整城市追逐的长期平衡性尚未全面实测。

## 项目性质

这是独立制作的学习和游戏原型作品，与 Rockstar Games / Take-Two 无关联，也不是官方 GTA 产品。全部画面由 Canvas 图形绘制，没有使用官方游戏资源。
